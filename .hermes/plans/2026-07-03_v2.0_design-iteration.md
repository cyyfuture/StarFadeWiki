### Task 2: 统一主题管理 → 单一 useTheme Hook

**目标:** 当前 `WikiHomePage.tsx` 和 `Header.tsx` 各自管理主题状态，存在冲突风险

**文件:**
- 新建: `src/hooks/use-theme.ts`
- 修改: `src/pages/WikiHomePage/WikiHomePage.tsx` — 用 `useTheme()` 替代本地 state
- 修改: `src/components/Header.tsx` — 用 `useTheme()` 替代本地 state

**代码骨架:**
```ts
// src/hooks/use-theme.ts
import { useState, useEffect, useCallback } from 'react';

const STORAGE_KEY = '__wiki_theme';
type Theme = 'dark' | 'light';

export function useTheme(): { theme: Theme; toggle: () => void } {
  const [theme, setTheme] = useState<Theme>(() => {
    const stored = localStorage.getItem(STORAGE_KEY);
    return stored === 'light' || stored === 'dark' ? stored : 'dark';
  });

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, theme);
    document.documentElement.classList.toggle('light', theme === 'light');
    // 或者 .dark class
    document.documentElement.classList.toggle('dark', theme === 'dark');
  }, [theme]);

  const toggle = useCallback(() => {
    setTheme((prev) => (prev === 'dark' ? 'light' : 'dark'));
  }, []);

  return { theme, toggle };
}
```

**验证:** 主题切换按钮正常工作，刷新页面保持主题偏好

### Task 4: 光照方案统一 — 移除硬编码颜色

**目标:** HeroSection 和部分组件使用了硬编码 RGB 颜色（如 `rgb(10_12_28)`, `rgb(0_200_255)`），切换主题后不变，视觉效果割裂

**文件:**
- 修改: `src/components/HeroSection.tsx` — 所有 `rgb(...)` → Tailwind class 或 CSS 变量
- 全局搜索: `search_files` 找所有 hardcoded `rgb(` 和 `#` 颜色

**替换映射:**
| 硬编码 | 替换为 |
|---|---|
| `bg-[rgb(10_12_28)]` | `bg-background` |
| `bg-[rgb(15_18_38_/_0.75)]` | `bg-card/75 backdrop-blur-sm` |
| `text-[rgb(140_190_220)]` | `text-muted-foreground` |
| `text-[rgb(0_200_255)]` | `text-primary` |
| `border-[rgb(0_200_255_/_0.12)]` | `border-primary/15` |
| `bg-[rgb(0_200_255_/_0.08)]` | `bg-primary/10` |
| `from-[rgb(0_220_255)]` | `from-primary` |
| `via-[rgb(100_200_255)]` | `via-blue-300` |
| `to-[rgb(255_200_80)]` | `to-accent` |
| `hsl(..., ..., ...)` shadow | 保留或用 `shadow-primary/30` |

**验证:** 两种主题下 HeroSection 都正确显示，不偏色

```tsx

const [localKeyword, setLocalKeyword] = useState('');
```
